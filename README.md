Milano Cortina 2026 Winter Olympics Website

A multi-page website showcasing the Milano Cortina 2026 Winter Olympic Games.

📖 Project Overview

This mini project is a static website built with HTML, CSS, and JavaScript that provides information about the upcoming 2026 Winter Olympics in Italy.

🌐 Pages

| Page | Description |
|------|-------------|
| index.html | Homepage with hero, sports, athletes, ceremonies, news, and FAQ |
| sports.html | All 15 Winter Olympic sports with details |
| venues.html | Olympic venue locations across Northern Italy |
| faq.html | Frequently Asked Questions about the Games |

✨ Features

- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **Modern CSS** - Gradients, animations, hover effects, and flexbox/grid layouts
- **Interactive Elements** - FAQ accordion, smooth scrolling, and animated buttons
- **Multi-page Navigation** - Consistent header navigation across all pages
- **Rich Content** - Sports info, athlete profiles, venue details, and more

🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling, animations, and responsive design
- **JavaScript** - Interactive FAQ toggles and smooth scrolling

🚀 How to Run
1. Download or clone the project folder
2. Open index.html in any web browser
3. Navigate through the site using the menu
